# 项目目录迁移实施计划

目标：采用用户已确认的 courses 配置、sources 输入、dist 产物三层结构。
架构：courses.json 保留有序课程 ID；各课程 metadata.json / structure.json 存放公开信息。scripts 读取配置，templates 保存页面资源。无原始资料的课程以 sources/<id>/site-snapshot 保存既有阅读页作为迁移输入，可从空 dist 重建。
约束：保留 Markdown 和图片字节；保留页面 URL 相对层级；不修改缺少源资料的正文；不提交或发布。

- [x] 添加目录约定测试，确认旧布局失败。
- [x] 迁移配置、资料、脚本、资源和静态快照，更新路径。
- [x] 更新注册脚本、命令、说明和部署规范。
- [x] 从空 dist 构建，验证测试、所有本地链接、源文件校验和及重复构建。

验证：npm test 通过；从空 dist 重建 192 个 HTML 页面；11436 个本地链接和资源引用有效；197 个原始文件哈希不变；重复构建输出哈希一致。
决策：未获取原始资料的课程使用明确标记的 site-snapshot 作为兼容输入，确保旧页面不丢失。页面 HTML 生成函数继续放在构建脚本中，templates 保存公共 CSS/JS，避免本次目录迁移扩大为模板引擎改造。
